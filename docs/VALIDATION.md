# 发布与验证记录

整理日期：2026-10-14。

基于用户提供的 `Student_Performance_Classification_System(2).zip` 创建副本，未修改原压缩包。

## 修复

1. 原流程先全量填补和归一化再切分，现改为先划分，再只使用训练样本拟合均值和 min/max。
2. 使用局部随机数生成器，固定划分不会改动全局随机状态。
3. 校验 CSV 必需列、K 值、训练样本数、特征维度及非有限数值。
4. 指标计算拒绝标签长度不匹配和未知标签，避免 zip 静默截断。
5. 修复从其他工作目录启动时的数据和输出路径。
6. 图形界面增加 NaN / Infinity 校验并调整初始尺寸。
7. 移除原包的 macOS 元数据、Python 缓存、课堂讲稿、答辩笔记及带无关运行报错的旧结果文件。

## 实际验证

- Python 3.13.9、Matplotlib 3.10.6。
- 8 项 unittest 测试通过；涵盖测试集极值不参与缩放、测试缺失值使用训练均值、常量列、非法输入、确定性投票、已知混淆矩阵及端到端结果。
- 从项目以外目录运行控制台入口成功，生成两张图表。
- Python 源文件编译检查通过。
- 测试用的精确混淆矩阵断言用于固定演示数据的回归，不意味着对真实数据具有同等准确率。
- 未启动桌面 GUI 做交互验收；Tkinter 模块可导入，但图形窗口布局与按钮操作仍需本机人工确认。
- 依赖使用本机已有安装验证，未在全新虚拟环境联网重装。
